# 📦 Campus Courier, Package And Hostel Delivery Collection System

A responsive, interactive frontend web application designed to streamline and manage campus courier, package, and hostel delivery collection workflows.

## ✨ Key Features
* **Package Logging Form:** Dedicated entry form for security guards to log incoming parcels using Student Name, Roll Number, Hostel Block, Courier Company, and the last 4 digits of the tracking ID.
* **Automated Token Generator:** Automatically generates a unique 4-digit Collection Pickup Token for every logged package.
* **Searchable Collection Board:** Real-time searchable dashboard where students can easily check if their parcel has arrived at the hostel/gate.
* **Package Handoff Verification:** Secure verification view where guards input the student's 4-digit pickup token to confirm identity and mark the parcel as **'Delivered'**.

## 🛠️ Technologies Used
* **HTML5** – Structure and layout
* **CSS3** – Responsive styling and UI design
* **JavaScript** – Dynamic token generation, search filtering, and state management
